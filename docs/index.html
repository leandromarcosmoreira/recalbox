Como instalar

1

Baixe a imagem

2

Descompacte

Extraia o arquivo .img.gz obtendo o arquivo .img

3

Grave no cartão

Use BalenaEtcher ou Raspberry Pi Imager para gravar em um SD card ou USB

4

Boot e aproveite!

Conecte o armazenamento ao seu dispositivo e initialize o Recalbox
