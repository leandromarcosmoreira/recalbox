Instale o `7z` e o `xsltproc`:
```bash
apt-get install 7zip xsltproc
```

Atualize os arquivos para um sistema:
```bash
python3 updater.py -target <nome do core>
```

Exemplo:
```bash
python3 updater.py -target fbneo
```
